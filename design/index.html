Design system

Design

Every page on this site is built from the same small set of colors, type, and components. The goal is a site that feels simple yet thoughtful and deep. Hand written in HTML, CSS, and JavaScript, with no framework and no build step.

Logo

The mark pairs the L and D of Long Duong into one shape. It is the favicon, the header mark, and the footer signature across the site.

  • Use the dark mark on light backgrounds, the white mark on dark ones.
  • Keep clear space around the mark on all sides, at least half its height.
  • Minimum size is 24px. It runs 30px in the header and footer, 54px in the hero.
  • Do not recolor, stretch, outline, or add effects.
  • The mark always links back to the homepage.

Motion is gentle: sections fade in and rise 26px over 0.7s as they enter the screen, cards lift a few pixels on hover, and every animation turns off when the visitor prefers reduced motion. Behind it all, a fixed canvas draws a quiet geometric mesh with soft pulsing dots. External links open in a new tab and carry a small arrow, like this link to LinkedIn.

Principles

  • Simple yet thoughtful and deep. If an element does not earn its place, it goes.
  • Accessibility is part of the design, not a pass at the end: AA contrast, visible focus, reduced motion respected.
  • Performance is a feature. Small pages, right sized images, no framework weight.
  • One system everywhere. A new pattern gets used on a second page only after it is written down here.
